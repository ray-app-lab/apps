제1장

Quantiventra란?

Quantiventra는 「Quantity」(수량)와 「Inventory」(재고)의 합성어입니다. 스마트폰 카메라로 바코드를 스캔해 재고 실사와 재고 관리를 간편하게 해 주는 Android 앱입니다.

카메라를 바코드에 향하면 자동으로 상품을 인식하고, 수량을 입력해 저장합니다. 직관적인 조작으로 종이 실사표를 디지털화할 수 있습니다. 결과는 CSV 파일로 저장되어 Excel이나 Google Sheets에서 편리하게 활용할 수 있습니다.

주요 기능

📦 재고 수량 파악

바코드 스캔으로 상품을 빠르게 인식하고 즉시 수량을 기록합니다. 내장 계산기로 여러 위치의 수량을 손쉽게 합산할 수 있습니다.

🗂️ 마스터 데이터 관리

상품·카테고리·위치를 마스터 데이터로 등록합니다. CSV 일괄 가져오기도 지원합니다.

📍 위치 관리

창고·매장·선반 등 여러 보관 위치를 등록해 위치별 재고를 관리합니다. 보충 판단에 포함할 위치도 설정할 수 있습니다.

📊 CSV 가져오기/내보내기

재고 목록·백업·이력을 CSV로 내보내 Excel이나 Google Sheets에서 집계합니다.

🌐 다국어 지원

일본어·영어·중국어·한국어 등 12개 언어를 지원합니다. 처음 실행할 때는 기기 언어를 참고해 표시 언어가 선택되며, 이후에는 앱의 언어 설정에서 직접 선택할 수 있습니다.

⭐ 전체 버전 기능

항목 수 제한을 해제하고 상세 위치 관리·재고 이동·실사 결과 반영 등 더 많은 기능을 잠금 해제합니다.

카메라 스캔 원리

화면 중앙의 가이드 프레임(파란색 또는 노란색 테두리)안에 바코드가 들어오면, 연속 3프레임에서 같은 코드를 인식했을 때 자동으로 확정됩니다. 세 번 확인하는 방식으로 오인식을 방지하면서도 안정적인 인식을 보장합니다.

💡 바코드가 인식되지 않을 때바코드가 가이드 프레임 안에 완전히 들어와야 합니다. 프레임 밖으로 벗어나면 인식되지 않습니다. 바코드 전체가 프레임 안에 들어오도록 카메라 위치를 조정하세요.

제3장

설치 및 첫 실행

  1. Google Play 스토어에서 「Quantiventra」를 검색하고 설치를 탭합니다.
  2. 앱 아이콘을 탭해 실행하면 카메라 권한 요청이 나타납니다. 허용을 탭합니다.
  3. 샘플 데이터 생성 안내가 나타나면 생성 또는 건너뛰기를 선택합니다.
  4. 앱 데이터 폴더가 내부 저장소에 자동으로 생성됩니다.
  5. 홈 화면이 표시되면 초기 설정이 완료된 것입니다.
⚠ 카메라 권한을 거부한 경우바코드 스캔을 사용할 수 없습니다. 다시 허용하려면 설정 → 앱 → Quantiventra → 권한 → 카메라 → 허용 순으로 진행하세요.

기기 변경 후 절차

  1. 이전 기기에서 설정 → 내보내기 또는 설정 → 공유를 사용해 데이터를 백업합니다.
  2. 새 기기에서 구매에 사용한 동일한 Google 계정으로 로그인합니다.
  3. Google Play에서 Quantiventra를 설치합니다.
  4. 설정 → 구매 복원을 실행해 구매한 플랜을 복원합니다.
  5. 필요한 경우 설정 → 마스터 CSV 가져오기로 백업한 CSV를 가져옵니다.
🚨 앱 삭제 시앱을 삭제하면 내부 저장소의 모든 데이터가 삭제됩니다. 내보내기 또는 공유를 통해 정기적으로 백업하는 습관을 들이세요.
제4장

데이터 저장

앱 데이터는 기기의 앱 전용 비공개 영역에 저장됩니다. 파일 관리자로 직접 편집하지 마세요. 앱의 공유 및 내보내기 기능을 통해 데이터에 접근하거나 백업하세요.

데이터 카테고리내용업데이트 시점
마스터 데이터상품·카테고리·위치 등 핵심 데이터항목을 등록·편집·비활성화할 때
실사 및 재고 이력실사·입고·출고·이동·CSV 가져오기 등의 기록항목을 저장하거나 가져올 때
앱 설정언어·스캔·코드 규칙·위치 설정 등설정을 변경할 때

Excel에서 CSV를 여는 방법

CSV 파일은 UTF-8 형식으로 저장됩니다. Excel에서 열 때는 아래 절차를 권장합니다.

  1. Excel을 열고 데이터 → 텍스트/CSV에서를 선택합니다.
  2. 열려는 CSV 파일을 선택합니다.
  3. 파일 원본 또는 인코딩에서 Unicode(UTF-8)을 선택합니다.
  4. 미리보기를 확인한 뒤 로드를 실행합니다.
⚠ CSV를 더블 클릭해 바로 열지 마세요환경에 따라 문자가 깨질 수 있습니다. Excel의 데이터 가져오기 기능을 사용하세요.

권장 백업 절차

  1. 설정 → 내보내기(폴더 선택)를 탭합니다.
  2. 기기의 Documents 폴더에 백업 폴더를 만들고 선택합니다(예:Quantiventra_backup_20250401).
  3. 이력 및 마스터 데이터 CSV 파일이 저장되면 완료됩니다.
  4. 더 안전하게 보관하려면 Google 드라이브 또는 USB 케이블로 PC에 복사하세요.

작업 흐름스캔 → 수량 입력 → 저장 → 확인입고/출고/이동 → 저장 → 이력 조회

제6장

빠른 시작(신규 사용자 가이드)

1단계: 샘플 데이터로 연습

  1. 앱을 실행하고 샘플 데이터 생성 안내가 나오면 생성을 선택합니다.
  2. 홈 화면에서 재고 관리를 열어 샘플 재고 현황을 확인합니다.
  3. 재고 실사를 열어 바코드 스캔과 수량 입력을 시험해 봅니다.
  4. CSV 파일 내보내기를 시도해 봅니다.
  5. 실제 운영 전에 샘플 데이터를 삭제합니다(설정 화면에서).

2단계: 상품 마스터 등록

  1. 홈 화면에서 마스터 관리를 엽니다.
  2. 상품 마스터에서 새 항목을 만들고 상품 코드와 이름을 입력합니다.
  3. 필요에 따라 카테고리·가격·보충 기준 수량을 설정합니다.
  4. 위치 마스터에 창고·매장 등을 등록합니다(표준 버전 이상 권장).
💡 팁샘플 데이터로 조작에 익숙해진 후 실제 상품 데이터를 입력하는 것을 권장합니다.

제12장

문제 해결

바코드가 스캔되지 않음 / 카메라가 반응하지 않음
  • 카메라 스위치(오른쪽 위)가 켜져 있는지 확인하세요.
  • 바코드가 가이드 프레임 안에 완전히 들어와야 합니다. 프레임 밖으로 벗어나면 인식되지 않습니다.
  • 설정(전체 버전)에서 스캔 유형(CODE39·EAN13 등)이 스캔하려는 코드 유형과 일치하는지 확인하세요.
  • 바코드가 손상되거나 오염된 경우 수동 입력으로 전환하세요.
마스터 CSV 가져오기 후 상품명이 표시되지 않음
  • CSV가 UTF-8로 인코딩되었는지 확인하세요(Shift-JIS는 글자가 깨집니다).
  • 헤더 행 형식을 확인하세요:barcode,name,theoretical_stock,actual_stock_total
  • 상품명에 쉼표가 포함된 경우 큰따옴표로 감싸세요: 예 "M6 볼트,스테인리스"
구매한 플랜 기능을 사용할 수 없음
  • 설정 → 구매 복원을 탭합니다.
  • 구매에 사용한 Google 계정으로 로그인했는지 확인하세요.
  • 인터넷 연결 상태를 확인하고 다시 시도하세요(구매 확인에 네트워크 연결이 필요합니다).
기기를 교체한 후 데이터가 사라짐
  • 데이터는 앱 내부 저장소에 저장되므로 앱 삭제나 기기 교체 시 사라집니다.
  • 내보내기 또는 공유를 통한 정기 백업을 강력히 권장합니다.
  • 백업이 있다면 마스터 CSV 가져오기로 복원할 수 있습니다.
