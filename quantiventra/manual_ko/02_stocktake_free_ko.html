제1장

무료 버전 재고 실사 개요

재고 실사는 현장에서 실제로 상품 수량을 세어 기록하는 작업입니다. 무료 버전에서는 기본적인 실사 작업을 체험할 수 있습니다.

실사 흐름은 상품 스캔 → 수량 입력 → 저장 → 이력 확인 입니다.

💡 실사란?실사는 직접 세어 확인한 수량(실제 수량)을 기록하는 작업입니다. 재고 관리의 입고·출고·이동 작업과는 별도의 작업이므로 혼동하지 마세요.

무료 버전 실사에서 가능한 기능

  • 상품 코드 또는 바코드 입력·스캔
  • 상품명 입력
  • 실제 수량 입력
  • 메모 입력
  • 실사 이력 확인
  • 무료 버전 한도 내 저장 및 내보내기

제3장

실사 단계별 작업

  1. 홈 화면에서 재고 실사를 탭합니다.
  2. 바코드를 스캔하거나 상품 코드를 수동으로 입력합니다.
  3. 상품명이 표시됩니다. 등록되지 않은 코드인 경우 직접 입력합니다.
  4. 위치를 확인하거나 선택합니다(창고·매장 등).
  5. 실제로 세어 확인한 수량을 입력합니다.
  6. 필요에 따라 메모를 입력합니다.
  7. 저장을 탭해 이 항목을 실사 이력에 기록합니다.
  8. 실사 이력에서 기록이 저장되었는지 확인합니다.
🚨 중요저장 전에 반드시 수량을 확인하세요. 입력 오류는 재고 데이터와의 불일치를 초래합니다.
💡 팁한 번의 세션에서 모든 실사를 완료할 필요는 없습니다. 앱을 중간에 종료해도 저장된 이력은 보존됩니다.
제4장

바코드·상품명·수량 입력

바코드 스캔

카메라를 실행해 바코드에 맞추면 자동으로 읽습니다. 읽히지 않을 때는 밝은 곳에서 다시 시도하거나 수동 입력으로 전환하세요.

상품 코드 수동 입력

바코드를 사용할 수 없는 경우에는 상품 코드 입력란에 상품 코드를 직접 입력합니다. 등록된 코드라면 상품명이 자동으로 표시됩니다.

상품명 입력

등록되지 않은 코드인 경우 상품명을 직접 입력합니다. 입력한 상품명은 실사 이력에 함께 기록됩니다. 마스터에 등록하지 않고 운영할 때는 기록 수 제한에 유의하세요.

실제 수량 입력

현장에서 실제로 세어 확인한 수량을 숫자로 입력합니다.

메모 입력

작업 메모나 비고를 자유롭게 입력할 수 있습니다. 메모는 실사 이력과 함께 저장됩니다.

필드설명필수/선택
바코드/상품 코드상품을 식별하기 위한 코드필수
상품명코드가 등록되어 있지 않은 경우 입력조건부 필수
위치실사를 실시하는 위치설정에 따라 다름
실제 수량현장에서 실제로 세어 확인한 수량필수
메모작업 메모 또는 설명선택
⚠ 주의실제로 세어 확인한 수량을 정확하게 입력하세요. 입력 오류는 재고 차이를 유발합니다. 저장 전에 숫자를 반드시 확인하세요.

⚠ 주의상세 위치를 등록했더라도 모드가 간단 A/B/C인 경우 상세 위치가 표시되지 않습니다. 상세 모드로 전환해야 합니다.
제6장

실사 이력 확인

저장된 모든 실사 항목은 실사 이력에서 확인할 수 있습니다. 저장 날짜·시간, 상품 코드·이름, 실제 수량, 위치, 메모가 표시됩니다.

⚠ 주의무료 버전은 최대 30건의 실사 이력을 저장합니다. 한도를 초과하면 새 실사 항목을 저장하지 못할 수 있습니다.

제9장

무료 버전 사용자를 위한 권장 워크플로

상품 수가 30종 이하라면 무료 버전으로도 기본적인 재고 실사를 계속 운용할 수 있습니다. 이력 30건 한도에 가까워지기 전에 CSV로 내보내 기록을 축적하세요.

💡 업그레이드 권장 시점상품이 30종을 초과하거나, 월별 실사 기록을 장기 보관하거나, 화면 방향을 고정해야 할 때는 표준 버전으로 업그레이드를 고려하세요.

📌 이 장의 핵심 요약

  • 무료 버전 실사는 30종 이하 상품의 소규모 작업에 적합합니다.
  • 작업 흐름: 스캔 → 수량 입력 → 저장 → 이력 확인.
  • 위치는 간단 A/B/C로 설정합니다. 상세 위치는 전체 버전가 필요합니다.
  • CSV 내보내기는 30건으로 제한되며 날짜·위치 컬럼이 포함되지 않습니다.
  • 기록이 30건에 가까워지면 표준 버전 또는 전체 버전 이용을 검토하세요.
  • 실사와 재고 관리는 독립된 모듈입니다. 혼동하지 마세요.

🔍 사용 전 확인 사항

  • 저장하기 전에 상품명, 위치, 수량을 확인하세요.
  • 저장 후 수정 가능 여부와 방법은 앱 화면의 안내를 따르세요.
  • 실사 이력이 30건에 가까워지면 CSV 내보내기 또는 표준/전체 버전 이용을 검토하세요.
  • 가격, 구매 조건, 환불 조건은 Google Play 표시를 우선해서 확인하세요.
