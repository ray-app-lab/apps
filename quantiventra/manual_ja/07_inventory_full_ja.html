第1章

フル版（フル解放）の概要

在庫管理 フル解放では、上限解除、詳細ルール、CSV拡張設定など、簡単版より細かい運用設定を利用できます。 入荷・出荷・在庫移動、棚卸結果の在庫への反映、CSVバックアップ・復元は、画面条件と案内に従って利用します。

フル解放で広がる主な範囲
  • マスタ件数・履歴件数・エクスポート件数の上限解除
  • 商品マスタの補充目安・価格を使った細かな管理
  • 品目カテゴリ管理
  • ロケーションマスタの登録・管理
  • 詳細ロケーション設定と組み合わせた在庫移動運用
  • 棚卸データ反映時の確認と履歴管理
  • CSV拡張設定とバックアップ運用
  • 履歴付きバックアップの継続運用
  • 登録済累計の直接編集
  • コードルール・ロケーションルール・カメラ読み取り設定（共通フル設定）
  • CSV拡張機能（列選択・取込方式の選択）
ヒント：フル解放 = 在庫管理フル版のこと このドキュメント内では「フル解放」と「フル版」を同じ意味で使っています。 購入・プラン確認は ① トップ・設定 の「課金プラン概要」を参照してください。

第3章

商品マスタ連携

商品マスタは、在庫を持つ実際の商品を登録する場所です。 商品ごとに補充目安・価格などを登録でき、在庫管理全体で活用できます。

商品マスタの主な項目

項目 説明 フル版で追加
商品コード / バーコード商品を一意に識別するコード—
商品名商品の名称—
品目商品の分類（カテゴリから選択）—
価格商品の販売価格または原価○
補充目安在庫が減ったときの補充基準数量○

商品の新規登録・編集手順

  1. トップ画面から「マスタ管理」を開く。
  2. 「商品マスタ」を選ぶ。
  3. 新規登録カードまたは「新規」ボタンをタップする。
  4. 商品コード・商品名・品目を入力し、必要に応じて価格・補充目安を入力する。
  5. 「保存」をタップして登録する。
  6. 既存の商品を編集するには、一覧から該当行を開いて修正し「保存」する。
入荷画面から未登録商品を登録する場合 入荷画面で未登録の商品コードを入力した場合は、商品マスタ新規登録へ進みます。商品マスタで商品名・販売価格・補充目安を登録すると、入荷画面へ戻り、登録した商品情報が自動反映されます。
注意：商品と品目を混同しない
  • 商品：実際に在庫を持つ個々の品物（例：ペン 赤、ペン 青）
  • 品目：商品を分類するカテゴリ（例：文具、食品）
品目は商品マスタで「分類」として選択します。品目自体に在庫は持ちません。
第4章

品目カテゴリ

品目カテゴリは、商品を分類するためのカテゴリを管理します。 カテゴリを整えると、商品マスタを分類して確認しやすくなります。

品目カテゴリの主な項目

項目 説明
カテゴリコードカテゴリを一意に識別するコード
カテゴリ名分類の名称（例：食品、衣類）
入力項目アプリ内の画面表示に従う
表示順一覧での並び順
ヒント：カテゴリについて カテゴリは商品を分類して見やすくするための項目です。 入力項目はアプリ内の画面表示に従ってください。

品目の登録手順

  1. 「マスタ管理」→「品目カテゴリ」を開く。
  2. 新規登録カードまたは「新規」ボタンをタップする。
  3. カテゴリコード・カテゴリ名・表示順を入力する。
  4. 「保存」をタップする。
第5章

ロケーションマスタ

ロケーションマスタでは、在庫を保管する「場所」を登録・管理します。 倉庫・店舗・棚など複数の場所を登録することで、場所別の在庫管理が可能になります。

ロケーションマスタの主な項目

項目 説明
ロケーションコード場所を一意に識別するコード
ロケーション名場所の名称（例：倉庫、店舗A）
表示順一覧での並び順
補充判定に含める在庫確認で補充対象を判断するときに、このロケーションの在庫を合計へ含める設定
有効 / 無効使用しないロケーションを無効化できる
基本ロケーション 初期状態では「倉庫」と「店舗」が登録されています。 業務に合わせてロケーション名・コードを変更・追加してください。

ロケーションの登録手順

  1. 「マスタ管理」→「ロケーションマスタ」を開く。
  2. 新規登録カードまたは「新規」ボタンをタップする。
  3. ロケーションコード・ロケーション名・表示順を入力する。
  4. 必要に応じて「補充判定に含める」のON/OFFを設定する。新規登録時はONが初期値です。
  5. 「保存」をタップする。
補充判定に含める設定 在庫確認の補充判定では、このチェックがONのロケーションだけを合計します。「すべて補充対象にする」ボタンで、アクティブなロケーションをまとめてONにできます。簡単A/B/C設定では作業導線の対象ロケーションが変わりますが、ロケーションマスタ上に倉庫や店舗の行が残ること自体は問題ではありません。
注意：ロケーションの無効化・削除 不要になったロケーションは削除ではなく「無効化」で対応することを推奨します。 削除や復元が必要な場合は、アプリ内の案内を確認してください。
第6章

在庫移動

在庫移動は、あるロケーションから別のロケーションへ在庫数量を移す操作です。 商品・在庫・2つ以上のロケーションなど、操作に必要な条件を満たすと利用できます。

在庫移動の手順

  1. 在庫管理メニューから「在庫移動」を開く。
  2. 移動元ロケーションを選択する。
  3. 移動先ロケーションを選択する。
  4. 対象の商品（バーコードまたは品名検索）を選ぶ。
  5. 移動する数量を入力する。
  6. 内容を確認して「確定」をタップする。
重要：元と先が同じロケーションへの移動はしない 移動元と移動先に同じロケーションを選ぶと、在庫データが正しく処理されません。 必ず異なるロケーション間で移動してください。
ロケーションが1つしかない場合 ロケーションが1つしか登録されていない場合は、在庫移動ではなく 「入荷」「出荷」「修正」で対応してください。 在庫移動は複数ロケーション間でのみ意味を持つ操作です。
第7章

在庫履歴

在庫履歴では、在庫の変動をすべて記録・確認できます。 フル解放では履歴件数の上限が解除され、長期間の履歴を保持できます。

履歴に記録される操作の種別

  • 入荷：商品の受け入れ
  • 出荷：商品の出庫・出荷
  • 移動：ロケーション間の在庫移動
  • 棚卸調整：棚卸結果を反映した差異調整
  • 初期在庫：初期登録時の数量設定
  • CSV取込：CSVによる在庫の更新
ヒント：履歴の確認方法 在庫履歴は商品単位・ロケーション単位・操作種別で絞り込める場合があります。 詳細な絞り込み方法は画面表示に従ってください。
第8章

棚卸データ反映

棚卸（実棚）の結果を在庫管理へ反映することで、現実の在庫数と一致させられます。 この操作は確認画面の条件を満たす場合に実行できます。

反映の仕組み

棚卸結果を在庫管理へ反映すると、理論在庫と実棚の差異が 「棚卸調整」の履歴 として記録されます。 これにより、在庫が実棚数量に更新されると同時に、調整の経緯が履歴として残ります。

反映条件と操作後の確認 棚卸データ反映では、反映タイミング・複数ロケーションの扱い・反映後の状態が画面に表示される場合があります。 実行前にアプリ内の確認画面をよく読み、反映後は在庫履歴とバックアップCSVで内容を確認してください。
重要：反映前にバックアップを取る 棚卸データ反映は在庫数量を書き換える操作です。 実行前に必ずCSVバックアップを取ってください。 反映後の取り消しに制限がある場合があります。
第9章

CSVバックアップ・復元

在庫管理では、在庫表CSV・バックアップCSVセット・履歴付きバックアップを利用できます。フル解放では、詳細設定や上限解除と組み合わせた運用がしやすくなります。 復元・置換はデータを大きく変更するため、操作前の確認と慎重な手順が重要です。

CSV種別と用途

CSV種別 用途 主な内容 使えるプラン 注意点
在庫表CSV 現在の在庫一覧の確認・取込 ロケーション、商品コード、商品名、数量 簡単版以上 ロケーション列がない場合は取込先ロケーションを選択
バックアップCSVセット データ一式のバックアップ・復元 商品、現在庫、入荷/出荷/移動/調整履歴、ロケーション、品目 フル版 複数ファイルに分かれる場合あり
履歴付きバックアップ 在庫の動きを後から確認するためのバックアップ 在庫表 + すべての操作履歴 フル版 履歴CSVの扱いはアプリ内の案内を確認
CSV出力モードの選択画面は、アプリ内の最新表示を確認してください。

バックアップCSVセットの出力手順

  1. 設定画面またはメインメニューから「CSV取込/出力」を開く。
  2. 「バックアップCSVセット」を選択する。
  3. 出力先フォルダを選択する（画面の指示に従う）。
  4. 「出力」をタップし、完了メッセージを確認する。

復元（CSV取込）の手順

  1. 「CSV取込/出力」→「復元」または「CSV取込」を開く。
  2. バックアップCSVファイルを選択する。
  3. 列のマッピングを確認する（自動で認識される場合がある）。
  4. 確認画面で内容を確認してから「実行」をタップする。
重要：復元・置換前には必ず現在のデータをバックアップする CSVによる復元・現在庫置換は既存の在庫データを上書きします。 操作前に必ず現在の在庫表CSVをエクスポートして保存してください。

現在庫置換について

現在庫置換は、取り込んだCSVの数量を現在庫として上書きする方式です。 既存の履歴は保持されますが、差分は 「調整」履歴 として記録されます。 CSVに含まれていない在庫行の数量が 0 に調整される場合があるため、取込前に十分確認してください。

現在庫置換は特に慎重に CSVに含まれていない商品・ロケーションの在庫が 0 に設定される可能性があります。 取込前にCSVの内容（商品数・ロケーション）を必ず確認してください。
第10章

履歴付きバックアップ

履歴付きバックアップは、在庫表と在庫の動き（入荷・出荷・移動・調整など）をまとめてエクスポートする機能です。 後から在庫の変動を追跡・確認したいときに使います。

  • 在庫表CSV（現在の在庫数量）
  • すべての操作履歴（入荷・出荷・移動・棚卸調整・CSV取込）
履歴CSVの再取込について 履歴付きバックアップを再取込する場合は、アプリ内の画面案内と対象ファイルを確認してから実行してください。
運用のヒント 月次・週次など定期的に履歴付きバックアップを出力しておくと、 トラブル発生時に在庫の変動を遡って確認できます。
第11章

補充目安・価格

補充目安

商品マスタに「補充目安」を設定すると、在庫数量がその数値を下回った際に目安として参照できます。 補充のタイミングを管理するための指標として使います。

在庫確認での補充判定 在庫確認の初期表示は商品ごとの合計です。補充判定は、ロケーションマスタで「補充判定に含める」がONのロケーション合計と、商品マスタの補充目安を比較して表示します。ロケーション別にばらして見る表示では、補充判定は表示しない、または無効として扱います。
補充目安の表示について 補充目安を下回った場合の表示や通知は、アプリ内の表示に従って確認してください。

価格

商品マスタに価格を登録できます。在庫の金額集計や出力時に参照します。 価格の表示・丸め方式は、アプリ内の表示に従って確認してください。

カテゴリとの組み合わせ

商品にカテゴリを紐付けることで、在庫一覧やマスタ管理で分類しやすくなります。 実際の表示や入力項目はアプリ内の画面表示に従ってください。

注意 価格情報の表示や計算はアプリ内の機能です。 会計処理・税務申告への利用可否は別途確認してください。
第12章

フル版向け業務運用例

運用例 1：倉庫＋店舗の2拠点管理

  1. ロケーションマスタに「倉庫」と「店舗A」を登録する。
  2. 商品マスタに商品を登録し、初期在庫を倉庫に設定する。
  3. 店舗への補充が必要になったら「在庫移動」で倉庫から店舗Aへ移動する。
  4. 店舗での販売後は「出荷」で数量を減らす。
  5. 定期的に棚卸を行い、「棚卸データ反映」で在庫を実数に合わせる。
  6. 月次で「履歴付きバックアップ」を出力して保存する。

運用例 2：定期棚卸サイクル

  1. 月末に棚卸アプリで実棚を入力する（棚卸 フル版）。
  2. 棚卸結果を確定（実棚確定）する。
  3. 「棚卸データ反映」で差異を在庫管理へ反映する。
  4. 反映後の在庫履歴で「棚卸調整」の記録を確認する。
  5. バックアップCSVセットを出力して保管する。
ヒント：棚卸との連携 棚卸フル版の詳細な操作は ④ 棚卸 フル版 を参照してください。
第13章

注意事項

CSV現在庫置換 現在庫置換はCSVの数量で在庫を上書きします。 CSVに含まれていない在庫行が 0 に設定される場合があります。 実行前に必ずバックアップCSVを出力してください。
棚卸データ反映 棚卸反映は在庫数量を書き換えます。 反映後は在庫履歴とバックアップCSVで内容を確認してください。 実行前に必ずバックアップCSVを出力してください。
マスタの削除・上書き 商品マスタ・ロケーションマスタの削除は在庫データに影響する可能性があります。 不要になったマスタは削除ではなく「無効化」を検討してください。 削除や復元が必要な場合は、アプリ内の案内を確認してください。
在庫移動の元・先が同じロケーション 在庫移動で移動元と移動先に同じロケーションを選ばないでください。 意図しないデータになる可能性があります。
出荷画面の在庫欄 出荷画面の在庫欄は現在庫を確認するための表示です。編集対象ではありません。出荷数量を保存した結果として、対象ロケーションの在庫が減ります。
価格・購入条件の確認 フル解放の購入価格・販売条件はGoogle Play上の表示を確認してください。 このドキュメントには価格を記載していません。
ヒント：操作の原則
  • 在庫を大きく変更する操作（置換・反映・削除）の前には必ずバックアップを取る。
  • CSV取込時はプレビュー・確認画面で内容を確認してから実行する。
  • ロケーションが1つの場合は在庫移動ではなく入荷・出荷・修正を使う。

📋 この章のポイント

  • フル解放では件数上限解除・詳細ルール・CSV拡張設定など、細かく管理するための機能が使える。
  • 商品マスタ（実在庫の商品）・品目カテゴリ（分類）・ロケーションマスタ（場所）の3種類のマスタを使い分ける。
  • 在庫移動は移動元と移動先が異なるロケーション間でのみ使用する。
  • 棚卸データ反映により、実棚と在庫管理の数量を同期できる。差異は「棚卸調整」履歴として記録される。
  • CSV現在庫置換・棚卸反映・削除などの不可逆操作の前は必ずバックアップを取る。
  • 月次・定期バックアップ（履歴付き）を習慣にすることで、データ復旧リスクを低減できる。

⚠️ ご利用前の確認事項

  • 棚卸データ反映を行う前に、確認画面で反映タイミング・対象ロケーション・差異調整の内容を確認してください。
  • 履歴付きバックアップを復元・再取込する場合は、対象ファイルとアプリ内の画面案内を確認してから実行してください。
  • 補充目安を下回った場合の表示・通知は、アプリ内の案内に従って確認してください。
  • 価格の通貨表示・丸め方式は、アプリ内の表示を確認して利用してください。
  • 不要になった商品・ロケーションは削除ではなく無効化を優先し、削除が必要な場合は事前にバックアップを取ってください。
  • フル解放の購入価格・販売条件は、Google Play上の表示を確認してください。
  • 在庫移動の確定後は在庫履歴で内容を確認し、誤りがある場合はアプリ内の案内に従って対応してください。
