제1장

표준 버전 개요

재고 실사 표준 버전은 마스터 데이터 수, 실사 이력 수, 내보내기 건수의 한도를 늘리고 화면 회전 잠금 기능을 사용할 수 있게 해, 현장에서 더 안정적으로 계속 운용하기 쉽도록 돕습니다.

기본적인 실사 작업 흐름은 무료 버전과 동일합니다. 다만 사용 가능한 건수 한도가 넓어져, 중소 규모 매장이나 창고에서도 더 오래 실사 기록을 관리할 수 있습니다.

항목무료 버전표준 버전
마스터 데이터 수최대 30건최대 300건
실사 이력 수최대 30건최대 1,000건
내보내기 건수최대 30건최대 300건
화면 회전 잠금✗○
상세 규칙 설정✗✗(전체 버전 필요)
제2장

무료 버전과의 차이

✅ 표준 버전에서 추가·확장되는 내용
  • 마스터 데이터 한도가 30건 → 300건으로 증가
  • 실사 이력 한도가 30건 → 1,000건으로 증가
  • 내보내기 한도가 30건 → 300건으로 증가
  • 화면 회전 잠금 기능 사용 가능
  • 현장에서 장기간 계속 사용하기 쉬워짐
💡 핵심 포인트표준 버전은 한도 확장과 화면 회전 잠금을 추가합니다. 실사 작업 흐름 자체는 무료 버전과 동일합니다. 상세 규칙 설정은 전체 버전이 필요합니다.
제3장

간단 A/B/C 모드

실사 설정에서 간단 A·간단 B·간단 C를 선택합니다. 선택한 모드에 따라 실사 등에서 표시되는 위치 옵션이 달라집니다.

모드표시 위치사용 예시
간단 A창고만단일 창고 운영
간단 B창고 + 매장창고와 매장 동시 실사
간단 C매장만단일 매장 운영
⚠ 주의전체 버전가 활성화되어 있어도 모드가 간단 A/B/C이면 간단 위치 옵션만 표시됩니다. 상세 모드로 전환해야 상세 위치를 사용할 수 있습니다.
제4장

기본 위치 처리

표준 버전의 기본 위치는 창고와 매장입니다. 실제 표시 이름은 기기의 주 언어와 앱 표시 언어에 맞춰 표시될 수 있습니다.

간단 모드의 위치 선택

실사 중 선택할 수 있는 위치는 설정한 간단 A/B/C 모드에 따라 달라집니다. 선택지가 단순해 입력 부담이 적고, 현장에서 빠르게 실사를 진행하기 쉽습니다.

상세 위치와의 차이

선반 번호, 구역, 층과 같은 세부 위치를 사용하려면 전체 버전 후 상세 모드로 전환해야 합니다. 표준 버전에서는 창고와 매장 같은 기본 위치 중심으로 운용하는 것이 적합합니다.

💡 운영 팁창고만 실사하는 경우에는 간단 A, 창고와 매장을 함께 실사하는 경우에는 간단 B, 매장만 실사하는 경우에는 간단 C를 선택하면 됩니다.
제5장

단계별 작업(표준 버전)

  1. 설정 → 실사 설정에서 현재 사용 중인 간단 모드(A/B/C)를 확인합니다.
  2. 홈 화면에서 재고 실사를 탭합니다.
  3. 바코드를 스캔하거나 상품 코드를 입력합니다.
  4. 상품명을 확인합니다(코드가 등록되어 있지 않으면 수동으로 입력합니다).
  5. 실사를 실시하는 위치를 선택합니다(창고·매장 등).
  6. 실제로 확인한 수량을 입력합니다.
  7. 선택적으로 메모를 입력합니다.
  8. 저장을 탭해 기록합니다.
  9. 다음 상품을 스캔하고 3~8단계를 반복합니다.
  10. 모든 상품 입력 후 전체 실사 이력을 확인합니다.
🚨 중요저장 전에 수량과 위치를 반드시 확인하세요. 잘못된 위치에 수량을 기록하면 재고 차이가 발생합니다.
제6장

표준 버전에서 편리해지는 점

화면 회전 잠금으로 현장 작업이 쉬워집니다

스마트폰을 들고 바코드를 스캔하거나 수량을 입력할 때 화면 방향이 불필요하게 바뀌지 않아 작업 흐름이 안정적입니다.

더 긴 실사 이력을 보관할 수 있습니다

무료 버전보다 훨씬 많은 이력을 저장할 수 있어 월별 실사나 정기 점검 기록을 장기적으로 관리하기 쉽습니다.

중소 규모 운용에 적합합니다

상품 수가 30종을 넘지만 300종 이하인 경우, 표준 버전은 간단한 위치 운용과 기록 보관을 함께 사용하기에 적합합니다.

제8장

중요 주의 사항

⚠ 실사 모드 설정 확인전체 버전이 활성화되어 있어도 직접 변경하기 전까지 모드는 간단 A/B/C 상태로 유지됩니다. 상세 위치를 사용하려면 상세 모드로 전환하세요.
🚨 가격 및 구매 조건현재 가격과 환불 조건은 반드시 Google Play Store에서 확인하세요. 이 매뉴얼은 확정적인 가격을 명시하지 않습니다.
제9장

무료에서 표준으로 업그레이드하는 이유

항목무료 버전→ 표준 버전
마스터 데이터 수최대 30건최대 300건(10배)
실사 이력최대 30건최대 1,000건(33배)
내보내기 레코드 수최대 30건최대 300건(10배)
화면 회전 잠금사용 불가사용 가능 — 현장 작업에 유리
운용 지속성한도에 도달하면 작업이 중단될 수 있음중장기 운용에 적합
💡 표준 버전 업그레이드 권장 시점
  • 상품이 30종을 초과할 때
  • 월별 실사 기록을 장기간 보관하고 싶을 때
  • 현장 작업 중 화면 방향을 고정하고 싶을 때
  • 상품이 300종 이하이고 실사를 계속 진행하고 싶을 때

📌 이 장의 핵심 요약

  • 표준 버전에서는 한도가 확장됩니다: 마스터 데이터 최대 300건, 이력 최대 1,000건, 내보내기 최대 300건.
  • 화면 회전 잠금 기능이 추가되어 현장 작업이 더 편해집니다.
  • 실사 모드는 간단 A(창고만)·간단 B(창고+매장)·간단 C(매장만)중 선택합니다.
  • 상세 규칙 설정은 전체 버전이 필요하며, 표준 버전에서는 사용할 수 없습니다.
  • 작업 흐름은 무료 버전과 동일합니다: 스캔 → 수량 입력 → 저장 → 이력 확인.

🔍 사용 전 확인 사항

  • 실사 결과를 재고에 반영하는 기능은 전체 버전에서 사용할 수 있습니다. 표준 버전에서는 실사 기록을 저장하고 확인하는 운용을 중심으로 사용하세요.
  • 마스터 데이터가 300건에 가까워지면 미리 CSV로 백업하고, 전체 버전 전환을 검토하세요.
  • CSV 내보내기 항목은 앱 화면과 실제로 내보낸 파일의 내용을 기준으로 확인하세요.
