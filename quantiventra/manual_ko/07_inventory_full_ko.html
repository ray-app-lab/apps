제1장

전체 버전(전체 버전 잠금 해제)개요

재고 전체 버전 잠금 해제는 마스터 레코드 수·이력 항목·내보내기 행수의 모든 제한을 해제하고, 표준 버전에서 사용할 수 없는 모든 고급 기능을 활성화합니다. 핵심 추가 기능은 다중 위치 관리(창고·매장 등), 위치 간 재고 이동, 실사 결과를 직접 재고에 반영, 전체 CSV 백업 및 복원입니다.

전체 버전 잠금 해제로 잠금 해제되는 기능
  • 마스터 레코드·이력 항목·내보내기 행수 무제한
  • 상품 마스터의 보충 기준 수량 및 가격 필드
  • 카테고리 마스터(상품 분류 관리)
  • 위치 마스터 등록 및 관리
  • 재고 이동(위치 간 수량 이동)
  • 실사 데이터를 재고에 반영
  • CSV 백업 및 복원(재고 시트 + 전체 백업 CSV 세트)
  • 이력 백업
  • 등록 누계 직접 편집
  • 코드 규칙·위치 규칙·카메라 스캔 설정(전체 버전 공유 설정)
  • 확장 CSV 옵션(컬럼 선택 및 가져오기 모드 선택)
참고:「전체 버전 잠금 해제」와 「전체 버전」은 같은 의미이 문서에서 「전체 버전 잠금 해제」와 「전체 버전」은 혼용됩니다. 구매 및 플랜 세부 내용은 ① 홈 및 설정의 「플랜 개요」 섹션을 참조하세요.

제3장

상품 마스터 통합

상품 마스터는 재고를 관리하는 실제 상품을 등록하는 곳입니다. 전체 버전 잠금 해제 후 각 상품에 보충 기준 수량과 가격을 추가할 수 있습니다.

상품 마스터의 핵심 필드

필드설명전체 버전에서 추가
상품 코드/바코드상품의 고유 식별자—
상품명상품 이름—
카테고리상품 분류(카테고리 마스터에서 선택)—
가격상품의 판매 가격 또는 원가✓
보충 기준 수량보충 여부를 판단할 때 참고하는 기준 수량✓

상품 등록 또는 편집

  1. 홈 화면에서 마스터 관리를 엽니다.
  2. 상품 마스터를 선택합니다.
  3. 새 항목 카드 또는 새로 만들기 버튼을 탭합니다.
  4. 상품 코드·이름·카테고리를 입력합니다. 선택적으로 가격과 보충 기준 수량을 입력합니다.
  5. 저장을 탭해 등록합니다.
  6. 기존 상품을 편집하려면 목록에서 해당 행을 열고 변경 후 저장을 탭합니다.
입고 화면에서 미등록 상품 등록입고 화면에서 마스터에 없는 상품 코드를 입력하면 상품 마스터 새 항목 양식으로 이동합니다. 상품명·가격·보충 기준 수량을 저장하면 입고 화면으로 돌아오고 상품 정보가 자동으로 채워집니다.
주의: 상품과 카테고리를 혼동하지 마세요
  • 상품:재고에 보유하는 개별 품목(예: 빨간 볼펜·파란 볼펜)
  • 카테고리:상품 분류 그룹(예: 문구류·식품)
카테고리는 상품 마스터에서 상품의 분류로 선택합니다. 카테고리 자체는 재고를 보유하지 않습니다.
제4장

카테고리 마스터

카테고리 마스터는 상품을 정리하기 위한 분류 그룹을 관리합니다. 카테고리를 사용하면 상품 마스터를 더 쉽게 필터링하고 확인할 수 있습니다.

필드설명
카테고리 코드카테고리의 고유 식별자
카테고리명분류 이름(예: 식품·의류)
분류목록과 마스터에서 상품을 정리하는 데 사용하는 그룹
표시 순서목록 보기에서의 정렬 순서

카테고리 등록

  1. 마스터 관리 → 카테고리 마스터로 이동합니다.
  2. 새 항목 카드 또는 새로 만들기 버튼을 탭합니다.
  3. 카테고리 코드·카테고리명·표시 순서를 입력합니다.
  4. 저장을 탭합니다.
팁: 카테고리카테고리를 일관되게 사용하면 상품을 묶고 마스터를 확인하기 쉽습니다.
제5장

위치 마스터

위치 마스터는 재고를 보관하는 물리적 장소를 등록하고 관리하는 곳입니다. 창고·소매 매장·각 선반 등 여러 위치를 등록해 위치별로 재고를 추적할 수 있습니다.

필드설명
위치 코드위치의 고유 식별자
위치명위치 이름(예: 창고·매장 A)
표시 순서목록 보기에서의 정렬 순서
보충 판단에 포함활성화하면 이 위치의 재고가 재고 조회 화면의 보충 판단 합계에 포함됨
활성/비활성더 이상 사용하지 않는 위치를 삭제하지 않고 비활성화 가능
기본 위치앱에는 「창고」와 「매장」이 미리 등록되어 있습니다. 실제 운영에 맞게 이름을 변경·편집하거나 위치를 추가하세요.

위치 등록

  1. 마스터 관리 → 위치 마스터로 이동합니다.
  2. 새 항목 카드 또는 새로 만들기 버튼을 탭합니다.
  3. 위치 코드·위치명·표시 순서를 입력합니다.
  4. 필요에 따라 보충 판단에 포함을 켜거나 끕니다. 새 항목은 기본으로 켜져 있습니다.
  5. 저장을 탭합니다.
「보충 판단에 포함」 설정에 대해재고 조회 화면의 보충 판단은 이 스위치가 켜진 위치의 재고만 합산합니다. 모든 활성 위치 포함 버튼을 사용하면 모든 활성 위치를 한 번에 켤 수 있습니다.
주의: 위치 비활성화 vs 삭제위치가 더 이상 필요하지 않을 때는 삭제보다 비활성화를 권장합니다. 삭제 가능 여부 및 삭제된 위치 복원 가능 여부는 확인이 필요합니다.
제6장

재고 이동

재고 이동은 지정 수량의 재고를 한 위치에서 다른 위치로 이동합니다. 전체 버전에서만 사용 가능합니다.

재고 이동 방법

  1. 재고 관리 메뉴에서 재고 이동을 엽니다.
  2. 출발 위치(이동할 위치)를 선택합니다.
  3. 도착 위치(이동될 위치)를 선택합니다.
  4. 바코드 스캔 또는 이름 검색으로 대상 상품을 찾습니다.
  5. 이동할 수량을 입력합니다.
  6. 내용을 확인하고 확인을 탭합니다.
중요: 같은 위치 간 이동은 절대 금지출발 위치와 도착 위치에 같은 위치를 선택하면 재고 데이터가 잘못 처리됩니다. 반드시 두 개의 다른 위치를 선택하세요.
위치가 하나뿐인 경우등록된 위치가 하나뿐이면 재고 이동은 의미가 없습니다. 대신 입고·출고 또는 편집으로 수량을 조정하세요. 재고 이동은 위치가 둘 이상일 때만 의미가 있습니다.
제7장

재고 이력

재고 이력은 재고의 모든 변동에 대한 완전한 기록을 제공합니다. 전체 버전 잠금 해제 후 이력 항목 제한이 해제되어 장기 기록을 유지할 수 있습니다.

이력에 기록되는 작업 유형

  • 입고:재고로 수령한 물건
  • 출고:재고에서 출고한 물건
  • 이동:위치 간 이동한 재고
  • 실사 조정:실사 결과 적용 시의 차이 수정
  • 기초 재고:최초 등록 시 설정한 초기 수량
  • CSV 가져오기:CSV 파일을 통해 가져온 재고
제8장

실사 데이터를 재고에 반영

실물 실사(수량 조사)결과를 재고 관리 모듈에 적용하면 시스템 재고와 선반의 실제 재고가 일치하게 됩니다. 전체 버전에서만 사용 가능합니다.

실사 결과를 재고에 반영하면 이론 재고 수준과 실제 수량 간의 차이가 이력에 실사 조정 항목으로 기록되고, 동시에 재고가 실제 수량으로 업데이트되며 추적 가능한 조정 기록이 보존됩니다.

적용 조건과 검토확인 화면의 조건이 충족될 때만 적용을 실행하세요. 진행 전에는 영향을 받는 위치, 조정 상세, 백업 CSV를 함께 검토하세요.
중요: 적용 전 반드시 백업실사 결과 반영은 재고 수량을 덮어씁니다. 이 작업을 실행하기 전에 반드시 CSV 백업을 내보내세요. 적용 완료 후 실행 취소 기능이 제한될 수 있습니다.
제9장

CSV 백업 및 복원

전체 버전 잠금 해제는 세 가지 내보내기 유형을 제공합니다: 재고 시트 CSV, 전체 백업 CSV 세트, 이력 백업. 복원 및 덮어쓰기 작업은 데이터를 대규모로 변경하므로 실행 전 신중한 확인이 필요합니다.

CSV 유형 및 용도

CSV 유형용도주요 내용사용 가능 버전비고
재고 시트 CSV현재 재고 목록 확인 및 재가져오기위치·상품 코드·상품명·수량표준 버전 이상위치 컬럼이 없으면 가져오기 시 대상 위치 선택
전체 백업 CSV 세트전체 데이터세트 백업 및 복원상품·현재 재고·입고/출고/이동/조정 이력·위치·카테고리전체 버전여러 파일로 내보내질 수 있음
이력 백업재고 변동 사후 검토를 위한 백업재고 시트 + 전체 작업 이력전체 버전이력 CSV를 다시 가져오기 전에 가져오기 화면을 검토

전체 백업 CSV 세트 내보내기

  1. 설정 화면 또는 메인 메뉴에서 CSV 가져오기/내보내기를 엽니다.
  2. 전체 백업 CSV 세트를 선택합니다.
  3. 대상 폴더를 선택합니다(화면 안내를 따릅니다).
  4. 내보내기를 탭하고 완료 메시지를 확인합니다.

CSV 백업에서 복원

  1. CSV 가져오기/내보내기 → 복원 또는 CSV 가져오기로 이동합니다.
  2. 백업 CSV 파일을 선택합니다.
  3. 컬럼 매핑을 확인합니다(앱이 자동으로 인식할 수 있습니다).
  4. 확인 화면을 꼼꼼히 읽은 후 실행을 탭합니다.
중요: 복원 또는 덮어쓰기 전에 반드시 현재 데이터를 백업CSV 복원 또는 현재 재고 덮어쓰기 작업은 기존 재고 데이터를 덮어씁니다. 진행하기 전에 반드시 현재 재고 시트 CSV를 내보내고 저장하세요.

현재 재고 덮어쓰기

현재 재고 덮어쓰기는 가져온 CSV의 값으로 현재 재고 수량을 덮어씁니다. 기존 이력은 보존되지만 차이는 조정 이력 항목으로 기록됩니다. CSV에 없는 재고 행은 0으로 설정될 수 있으므로 가져오기 전에 반드시 CSV 내용을 확인하세요.

현재 재고 덮어쓰기는 신중하게 사용CSV에 없는 상품이나 위치의 재고가 0으로 설정될 수 있습니다. 가져오기 전에 CSV에 올바른 상품과 위치가 포함되어 있는지 확인하세요.
제10장

이력 백업

이력 백업은 재고 시트와 재고 변동의 완전한 기록—입고·출고·이동·조정 등—을 한 번의 작업으로 내보냅니다. 나중에 재고 변동을 감사하거나 추적해야 할 때 사용합니다.

  • 재고 시트 CSV(현재 재고 수량)
  • 전체 작업 이력(입고·출고·이동·실사 조정·CSV 가져오기)

제11장

보충 기준 수량·가격

보충 기준 수량

상품 마스터에 보충 기준 수량을 설정하면 보충 판단에 사용할 기준값을 만들 수 있습니다: 재고가 이 값 아래로 떨어지면 보충을 검토해야 하는지 쉽게 판단할 수 있습니다. 보충 시점을 검토하는 데 사용하는 참고 지표입니다.

재고 조회 화면의 보충 판단재고 조회 화면은 기본적으로 상품별 합계를 표시합니다. 보충 판단은 보충 판단에 포함이 켜진 모든 위치의 합계 재고와 상품의 보충 기준 수량을 비교합니다. 개별 위치별 재고를 볼 때는 보충 판단이 표시되지 않거나 비활성화된 것으로 처리됩니다.
보충 기준 수량 관련 표시현재 설정에서 보충 기준 수량과 관련 안내가 어떻게 표시되는지는 재고 확인 화면을 기준으로 확인하세요.

가격

상품 마스터에서 각 상품에 가격을 등록할 수 있습니다. 재고 총 가치를 계산하거나 보고서를 작성할 때 참조됩니다. 통화 설정과 반올림 방식의 세부 내용은 확인이 필요합니다.

카테고리와 함께 사용

상품을 카테고리에 연결하면 마스터를 정리하고 상품 유형별로 목록을 확인하기 쉬워집니다.

주의가격 정보와 관련 계산은 앱 기능입니다. 업무 기록에 적합한지는 별도로 확인해 주세요.
제12장

전체 버전 워크플로 예시

예시 1: 두 위치 관리—창고와 매장

  1. 위치 마스터에 「창고」와 「매장 A」를 등록합니다.
  2. 상품 마스터에 상품을 등록하고 창고에 기초 재고를 설정합니다.
  3. 매장에 보충이 필요할 때 재고 이동으로 창고에서 매장 A로 재고를 이동합니다.
  4. 매장에서 판매 후 출고로 감소분을 기록합니다.
  5. 정기적으로 실사를 실시하고 실사 결과 반영으로 시스템 재고와 실제 수량을 일치시킵니다.
  6. 매월 이력 백업을 내보내 보관합니다.

예시 2: 정기 실사 주기

  1. 월말에 실사 앱(실사 전체 버전)으로 실제 수량을 입력합니다.
  2. 실제 수량 결과를 확정합니다.
  3. 실사 결과 반영으로 차이를 재고 모듈에 반영합니다.
  4. 재고 이력에서 실사 조정 항목을 확인해 변경 내용을 검증합니다.
  5. 전체 백업 CSV 세트를 내보내 저장합니다.
팁: 실사 통합실사 전체 버전의 상세 안내는 ④ 재고 실사: 전체 버전을 참조하세요.
