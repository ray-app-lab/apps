Kebijakan Privasi

Ray App Lab (selanjutnya disebut "Pengembang") menetapkan Kebijakan Privasi berikut mengenai penanganan informasi pengguna dalam aplikasi Android "Quantiventra" (selanjutnya disebut "Aplikasi").

1. Pengumpulan dan Penggunaan Informasi Pribadi

Aplikasi tidak mengumpulkan atau memperoleh informasi pribadi apa pun seperti nama, alamat, nomor telepon, maupun alamat email. Aplikasi tidak membagikan informasi pribadi kepada pihak ketiga. Koneksi jaringan dapat terjadi melalui Google Play saat pembelian atau pemulihan pembelian.

2. Tujuan Izin Perangkat

Aplikasi hanya meminta izin perangkat berikut untuk mengaktifkan fitur utama. Tidak ada izin yang digunakan di luar tujuan yang dinyatakan.

  • Kamera (CAMERA): Digunakan khusus untuk memindai barcode dan kode 2D. Tidak ada foto atau video yang direkam, disimpan, maupun dikirimkan.
  • Pemilihan dan Berbagi File: File CSV hanya dibaca (diimpor) atau ditulis (diekspor) di lokasi atau tujuan yang dipilih pengguna. Aplikasi tidak meminta izin penyimpanan persisten untuk mengakses file perangkat secara bebas.

3. Penyimpanan dan Keamanan Data

Semua data yang dimasukkan atau dipindai dalam Aplikasi hanya disimpan di perangkat pengguna. Pengembang tidak memiliki akses ke data pengguna. Pengguna bertanggung jawab atas pengelolaan data mereka sendiri.

Saat membeli paket atau memulihkan pembelian sebelumnya, koneksi jaringan melalui Google Play dapat terjadi untuk memverifikasi status pembelian. Untuk ketentuan pembelian dan pengembalian dana, lihat Google Play.

4. Perubahan Kebijakan

Pengembang dapat merevisi Kebijakan ini untuk menyesuaikan dengan perubahan hukum atau pembaruan Aplikasi. Perubahan penting akan dikomunikasikan di halaman ini.

5. Kontak

Untuk pertanyaan mengenai Kebijakan ini, gunakan informasi kontak di situs web kami atau informasi pengembang di daftar toko aplikasi.
