제1장

표준 플랜 개요

재고 표준 플랜은 무료 플랜보다 더 많은 레코드를 지원합니다. 일상적인 입고, 출고, 재고 조회, 재고 이력 작업을 여유 있게 운영할 수 있으며, 위치 관리 범위도 확장됩니다.

표준 플랜 한도

항목무료 플랜표준 플랜
마스터 레코드최대 30건최대 300건
재고 이력 레코드최대 30건최대 1,000건
내보내기 레코드최대 30건최대 300건
화면 회전 잠금✗○
위치 마스터 등록무료 플랜에서는 제한됨표준 플랜 한도 내에서 사용 가능
등록된 누적 합계 직접 편집✗✗ (전체 플랜 필요)
제2장

무료 플랜과의 차이

✅ 표준 플랜에서 추가 또는 확장되는 내용
  • 마스터 레코드 한도가 30건 → 300건으로 증가
  • 재고 이력 한도가 30건 → 1,000건으로 증가
  • 내보내기 한도가 30건 → 300건으로 증가
  • 화면 회전 잠금을 사용할 수 있음
  • 위치 관리 범위 확장
  • 일상적인 입고, 출고, 재고 조회, 이력을 지속적으로 관리하기 쉬워짐
제3장

입고

입고 작업은 재고를 늘립니다. 상품이 도착했을 때, 예를 들어 구매, 수령, 이와 유사한 거래에 사용합니다.

입고 절차

  1. 재고 관리 → 입고로 이동합니다.
  2. 바코드를 스캔하거나 상품 코드를 입력합니다.
  3. 상품명을 확인합니다. 코드가 등록되어 있지 않으면 새 상품 마스터 항목 생성을 진행합니다.
  4. 새 상품 마스터 항목에 상품명, 판매 가격, 재주문 기준을 등록합니다.
  5. 저장한 뒤 입고 화면으로 돌아오면, 등록된 상품 코드와 상품명이 자동으로 채워집니다.
  6. 도착 위치를 선택합니다(창고, 매장 등).
  7. 입고 수량을 입력합니다.
  8. 저장을 탭합니다. 수량이 즉시 재고에 추가됩니다.
  9. 재고 조회 또는 재고 이력에서 업데이트 내용을 확인합니다.
💡 상품 마스터 속성 정보판매 가격과 재주문 기준은 상품 마스터에서 관리되는 속성입니다. 각 입고 거래마다 입력하는 항목이 아닙니다. 일반적인 입고 화면에서는 수량, 위치, 메모 입력에 집중하세요.
⚠ 참고입고는 재고에 즉시 반영됩니다. 저장하기 전에 항상 수량과 위치를 확인하세요. 저장 후 잘못된 수량을 발견한 경우 재고 이력을 확인하고, 앱 내 안내에 따라 수정, 되돌리기 또는 조정 기록을 적절히 처리하세요.
제4장

출고

출고 작업은 재고를 줄입니다. 판매, 외부 반출, 배송 및 이와 유사한 거래에 사용합니다.

출고 절차

  1. 재고 관리 → 출고로 이동합니다.
  2. 바코드를 스캔하거나 상품 코드를 입력합니다.
  3. 상품명을 확인합니다.
  4. 출발 위치를 선택합니다(재고가 빠져나가는 위치).
  5. 출고 수량을 입력합니다.
  6. 저장을 탭합니다. 수량이 즉시 재고에서 차감됩니다.
  7. 재고 조회 또는 재고 이력에서 업데이트 내용을 확인합니다.
💡 재고 필드 정보출고 화면의 재고 필드는 선택한 상품과 위치의 현재 재고를 참고용으로 표시하는 필드입니다. 편집 가능한 입력 필드가 아닙니다. 출고 수량을 저장하면 그 결과로 재고가 감소합니다.
🚨 중요현재 재고를 초과하는 출고 수량을 입력하지 마세요. 출고할 수량을 입력하기 전에 위치별 재고 수준을 확인하세요.
제5장

재고 조회

재고 조회는 처음에 상품별 통합 재고 합계를 표시합니다. 보충 필요 여부는 “보충 확인에 포함”이 켜져 있는 모든 위치의 총 재고를 상품 마스터의 재주문 기준과 비교하여 판단합니다.

재고 조회 절차

  1. 재고 관리 → 재고 조회로 이동합니다.
  2. 확인할 상품을 찾습니다(검색하거나 목록을 스크롤).
  3. 재주문 기준보다 낮은 상품을 확인합니다(보충이 필요한 상품으로 표시됨).
  4. 상품을 탭하면 위치별 재고 내역, 이력, 상세 정보를 볼 수 있습니다. 위치별 내역 화면에서는 보충 필요 여부가 표시되지 않거나 비활성 상태로 처리됩니다.
제6장

재고 이력

재고 이력은 모든 입고, 출고, 이동, 재고 실사 조정, 초기 재고, CSV 가져오기 작업의 로그를 표시합니다.

재고 이력에서 확인할 수 있는 항목

  • 날짜/시간 및 작업 유형(입고, 출고, 이동, 조정 등)
  • 상품 코드 및 상품명
  • 위치와 수량 변동
  • 메모
💡 팁재고 수량이 맞지 않는 경우 재고 이력을 거슬러 확인하여 입력 오류나 예상치 못한 조정이 있었는지 점검하세요.
제7장

위치 관리

표준 플랜은 주로 기본 위치인 “창고”와 “매장”을 사용합니다.

모드사용 가능한 위치
간단 A창고만
간단 B창고 + 매장
간단 C매장만

재고 이동

재고 이동은 재고 수량을 한 위치에서 다른 위치로 옮기는 작업입니다.

⚠ 참고같은 위치 사이로 이동하지 마세요. 위치가 하나뿐인 경우(예: 간단 A) 재고 이동은 필요하지 않습니다. 대신 입고, 출고 또는 수정 작업을 사용하세요.
💡 팁상세 위치(예: 선반 번호)를 사용하려면 설정에서 상세 모드로 전환해야 합니다. 상세 모드는 전체 플랜 기능을 사용할 때 사용됩니다.
제8장

CSV 가져오기 / 내보내기

재고 관리는 CSV 파일을 사용하여 재고 데이터를 가져오기, 내보내기, 백업할 수 있습니다.

🚨 중요CSV 가져오기 작업은 데이터를 크게 변경할 수 있습니다. 가져오기 전에 반드시 백업 CSV를 내보내세요.

재고 CSV 사양

CSV 유형용도주요 컬럼필수/선택비고사용 가능 플랜
재고 CSV(위치 컬럼 포함)위치별 재고 데이터 가져오기location, item_code, quantity, product_namelocation, item_code, quantity 필수; product_name은 조건부 필수등록되지 않은 코드에는 product_name 컬럼 필요재고 표준 플랜 이상
재고 CSV(위치 컬럼 없음)지정 위치의 재고 데이터 가져오기item_code, quantity, product_nameitem_code, quantity 필수가져오기 시 대상 위치 선택재고 표준 플랜 이상
백업 CSV전체 데이터 백업 및 복원상품, 현재 재고, 위치, 카테고리 — 여러 파일전체 백업 세트 필요여러 파일로 나뉠 수 있음재고 표준 플랜 이상

컬럼 매핑 화면 사용

CSV를 가져올 때 어느 컬럼이 상품 코드, 상품명, 수량, 위치 등에 해당하는지 선택합니다.

  1. CSV 파일을 선택합니다.
  2. 컬럼 매핑 화면에서 각 CSV 컬럼을 해당 필드(상품 코드, 수량 등)에 할당합니다.
  3. 할당 내용을 확인하고 가져오기를 실행합니다.
⚠ 자주 발생하는 CSV 가져오기 오류
  • 필수 컬럼 누락
  • 같은 컬럼이 둘 이상의 필드에 할당됨
  • 수량 컬럼이 비어 있거나 숫자가 아님
  • 등록되지 않은 코드에 대해 상품명 컬럼을 선택하지 않음
  • 위치 컬럼이 없고 대상 위치도 선택하지 않음
  • CSV가 비어 있거나 가져올 수 있는 행이 없음
제9장

현재 재고 덮어쓰기

현재 재고 덮어쓰기는 파일의 수량을 새로운 현재 재고로 처리하는 CSV 가져오기 모드입니다. 기존 이력은 보존되며, 차이는 조정 이력 항목으로 기록됩니다.

🚨 중요: 현재 재고 덮어쓰기는 신중하게 사용하세요
  • CSV에 포함되지 않은 재고 행은 0으로 설정될 수 있습니다.
  • 이 작업은 기존 재고 데이터에 큰 영향을 줄 수 있으므로 반드시 먼저 백업하세요.
  • 실행하기 전에 확인 화면을 주의 깊게 읽으세요.

현재 재고 덮어쓰기 절차

  1. 백업 CSV를 내보냅니다(필수).
  2. 재고 관리 → CSV 가져오기 → 현재 재고 덮어쓰기로 이동합니다.
  3. 가져올 CSV 파일을 선택합니다.
  4. 매핑 화면에서 컬럼 매핑을 확인합니다.
  5. 확인 화면에서 덮어쓰기 상세 내용(조정 내용)을 신중하게 검토합니다.
  6. 문제가 없으면 가져오기를 실행합니다.
  7. 재고 이력에서 조정 항목을 확인합니다.
제10장

입고로 추가

입고로 추가는 파일의 수량을 기존 재고에 입고 거래로 더하는 CSV 가져오기 모드입니다. 현재 재고 덮어쓰기와 달리 현재 재고를 덮어쓰지 않고 더합니다.

가져오기 모드동작사용 예
현재 재고 덮어쓰기CSV 수량을 새로운 현재 재고로 처리합니다. 차이는 조정 이력으로 기록됩니다.재고 실사 후 재고 수정, 초기 설정
입고로 추가CSV 수량을 현재 재고에 입고로 추가합니다.대량 입고 일괄 가져오기
💡 팁처음 재고를 설정할 때는 현재 재고 덮어쓰기를 사용하고, 기존 재고에 수량을 추가할 때는 입고로 추가를 사용하세요. 실행하기 전에 어떤 모드가 필요한지 확인하세요.
제11장

중요 참고 사항

⚠ 상세 위치 설정상세 위치를 사용하려면 설정에서 상세 모드로 전환하세요. 아직 간단 A/B/C 모드인 경우 상세 위치가 표시되지 않습니다.
⚠ 작업 전 위치와 수량 확인입고, 출고, 이동, CSV 가져오기는 재고에 즉시 반영됩니다. 각 작업 전에 위치와 수량을 확인하세요.
🚨 CSV 작업 전 백업현재 재고 덮어쓰기, 입고로 추가, 백업 복원 작업 전에는 항상 백업을 수행하세요.
제12장

권장 워크플로

매일 입고와 출고 기록

  • 상품이 들어올 때마다 입고를 통해 들어온 재고를 등록합니다.
  • 상품이 나갈 때마다 출고를 통해 나간 재고를 기록합니다.
  • 상품 마스터에 재주문 기준을 설정하고 재고 조회를 사용해 보충 시점을 확인합니다.

정기 재고 확인

  • 주간, 월간 또는 필요 시 정기적으로 재고 수량을 확인합니다.
  • 재고 실사와 함께 사용하여 실제 수량이 재고 기록과 일치하는지 주기적으로 검증합니다.

정기 백업

  • 최소 월 1회 백업 CSV를 내보내 PC 또는 클라우드 저장소에 보관합니다.
💡 다음과 같은 경우 전체 플랜 업그레이드를 검토하세요
  • 재고 실사 결과를 재고에 자동으로 반영하고 싶은 경우
  • 등록된 누적 재고 합계를 직접 편집해야 하는 경우
  • 상품 수가 300개를 초과하는 경우

📌 이 장의 핵심 요약

  • 표준 플랜은 한도를 높입니다: 마스터 레코드 최대 300건, 이력 레코드 최대 1,000건, 내보내기 레코드 최대 300건.
  • 입고와 출고는 재고에 즉시 반영됩니다. 저장하기 전에 수량과 위치를 확인하세요.
  • 재고 이력은 모든 입고, 출고, 이동, 조정 작업의 전체 로그를 표시합니다.
  • CSV 가져오기에는 현재 재고 덮어쓰기와 입고로 추가의 두 가지 모드가 있습니다. 두 모드 모두 실행 전 백업이 필요합니다.
  • 위치는 간단 A/B/C로 설정합니다. 상세 위치를 사용하려면 상세 모드로 전환하세요.
  • 등록된 누적 합계를 직접 편집하려면 전체 플랜이 필요합니다.

🔍 사용 전 참고 사항
